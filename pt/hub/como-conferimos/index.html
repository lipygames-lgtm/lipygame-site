Como conferimos cada código

LHPor Equipe Lipy Hub·Atualizado em 28 de setembro
Em resumo

Todo código passa por uma conferência nas fontes oficiais do jogo antes de entrar na lista, e mostramos a hora dessa conferência. Código sem origem confiável não entra.

Onde conferimos

Nos canais oficiais de cada jogo: as redes sociais do jogo ou do estúdio, o Discord oficial, a página oficial do jogo (como a descrição no Roblox) e os sites oficiais de resgate. Cada página de códigos lista os canais conferidos, com link.

O que cada selo quer dizer

  • Fonte oficial: o código foi publicado pelo próprio jogo ou pelo estúdio.
  • Confirmado em 2 fontes: o código aparece como ativo em fontes independentes, que não copiam umas das outras.
  • Código com uma fonte só, ou em que as fontes discordam, não entra na lista.

Como identificamos listas recicladas

Muitas listas repetem os mesmos códigos por meses. Desconfiamos quando a mesma lista aparece igual para regiões diferentes, quando códigos antigos voltam como "de hoje", quando a sequência segue as teclas do teclado (como Q-W-E-R-T-Y) ou quando o código tem um tamanho que o jogo não aceita.

Os votos dos jogadores

Em cada código há os botões "funcionou" e "não funcionou". Os votos ajudam a tirar da lista, rápido, o código que parou de funcionar.

O que não prometemos

Não testamos cada código dentro do jogo: muitos valem uma vez por conta e alguns só para certas regiões. Quando um código tiver sido testado no jogo, ele vai ganhar um selo próprio.

Quando não existe código oficial ativo, dizemos isso na página, com a hora da conferência. Preferimos uma lista vazia e verdadeira a uma lista cheia de códigos que não funcionam.

Achou um erro?

Escreva para bluetubeoficial@gmail.com com o nome do jogo e o código. Corrigimos assim que confirmarmos.
