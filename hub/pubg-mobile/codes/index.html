How to redeem

  1. Find your Character IDIn the game, tap your avatar in the corner of the screen. The number under your name is your Character ID. Copy it.
  2. Open the official redemption centerPUBG MOBILE global: midasbuy.com/midasbuy/ot/redeem/pubgm. BGMI (India): battlegroundsmobileindia.com/redeem. Use your phone's or computer's browser.
  3. Paste the ID, the code and the verificationEnter your Character ID, paste the code exactly as shown and type the verification code that appears on the screen.
  4. Tap Redeem and check the nameThe site shows the account name before you confirm. Make sure it's yours.
  5. Claim the reward in the in-game MailOpen the game and go to Mail. In BGMI, unclaimed rewards disappear after 30 days.

Where PUBG MOBILE codes come from

In global PUBG MOBILE, codes come out on the official social accounts (X, Instagram, YouTube) and in events and partnerships. Some, like the ones from the Naruto collab in September 2026, only work inside the in-game event, not in the redemption center.

In BGMI, KRAFTON India releases batches of about 50 codes with an end date. Each code only works for a few people (10 per code in the September batch), first come, first served. That's why BGMI codes run out in minutes.

Why isn't my code working?

  • The code expired or ran out: BGMI codes are gone after a few people use them.
  • Wrong region: BGMI codes don't work in global PUBG MOBILE, and vice versa.
  • Wrong Character ID: copy the number from your in-game profile.
  • You already used it: each code works once per account. In BGMI, only one code per day per account.
  • Guest account: BGMI doesn't allow redeeming on a guest account.
  • Event code: some only work on the event screen inside the game.

Common PUBG MOBILE scams

  • Free UC doesn't exist: UC can only be bought in the game or the official store (Midasbuy).
  • Sites asking for your password or login to "unlock" a code: the official centers only ask for your Character ID.
  • Lists of "UC codes": official codes give items and coupons, almost never UC.
  • Codes that require downloading an app or filling out a survey: real codes just get pasted into the official center.

Frequently asked questions

Where do I redeem PUBG MOBILE codes?
For the global version, the official redemption center on Midasbuy (midasbuy.com/midasbuy/ot/redeem/pubgm). For BGMI, battlegroundsmobileindia.com/redeem. Be wary of any other address.
Do BGMI codes work in PUBG MOBILE?
No. They're separate games with separate accounts and redemption centers.
Are there free UC codes?
No. UC can only be bought. Anyone promising free UC in exchange for your login is running a scam.
Why is the list empty?
Because a code only gets in if it came out on the official channels or independent sources confirm it as active. In our check, none were confirmed.
