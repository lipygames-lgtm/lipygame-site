How we check every code

LHBy Lipy Hub Team·Updated September 28
In short

Every code is checked against the game's official sources before it goes on the list, and we show the time of that check. Codes without a trustworthy source stay out.

Where we check

On each game's official channels: the game's or studio's social media, the official Discord, the game's official page (like its description on Roblox), and the official redemption sites. Every codes page lists the channels we checked, with links.

What each badge means

  • Official source: the code was published by the game itself or by its studio.
  • Confirmed by 2 sources: the code is listed as active by independent sources that don't copy each other.
  • A code with only one source, or one the sources disagree on, stays off the list.

How we spot recycled lists

Many lists repeat the same codes for months. We get suspicious when the same list shows up unchanged for different regions, when old codes come back as "today's," when the sequence follows the keys on a keyboard (like Q-W-E-R-T-Y), or when a code has a length the game doesn't accept.

Player votes

Every code has "it worked" and "didn't work" buttons. The votes help us quickly pull codes that have stopped working.

What we don't promise

We don't test every code in the game: many work only once per account, and some only in certain regions. When a code has been tested in the game, it will get its own badge.

When there's no active official code, we say so on the page, with the time of the check. We'd rather show an empty, honest list than a full list of codes that don't work.

Found a mistake?

Email bluetubeoficial@gmail.com with the game's name and the code. We'll fix it as soon as we confirm it.
