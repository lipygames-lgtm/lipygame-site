Where Anime Dice codes come from

Anime Dice is made by More & More Games, a Roblox group with over 900,000 members. The game was created on August 15, 2026, and is on Update 6. Its official description doesn't list codes: according to sites that track the game, they're posted on the studio's Discord server (discord.gg/anime-dice), which you can only read with an account.

The names tell you where they came from: UPDATE1 to UPDATE6 arrived with the updates, 1KCCU to 40KCCU with concurrent player milestones, and 100KLIKES to 400KLIKES with like milestones. On September 28, 2026, the game had over 436,000 likes on Roblox.

UPDATE6 and 400KLIKES showed up along with Update 6, which started on September 27, 2026, according to the game's official event on Roblox. As of our check, no source listed the older codes as expired.

Why some rewards show no amount

The sites that list Anime Dice codes disagree on reward sizes, especially for new codes. When two independent sources give the same number, we show it. When they don't match, we show only the reward type, without guessing the amount.

How we check

Before a code goes on the list, it's checked against the official source (when the game publishes its codes) or against two independent sources. We show where each one comes from:

Frequently asked questions

Why is JPCALLING under "May have expired"?
Because the sources disagree on it. One site marks the code as limited-use and another already lists it as expired, while others still list it as active. Limited-quantity codes usually run out in the first few hours. That's why it appears in that section, below the active ones: the active list only includes codes that are official or confirmed by two independent sources.
What are Lucky Spins, Trait Rerolls, Gems, and Tickets?
A Lucky Spin raises your chance of getting a rare character on a dice roll. A Trait Reroll swaps a character's trait. Gems are used for upgrades, and Tickets for buying things in the in-game shop.
Why didn't the code work?
Make sure you copied it exactly, in capital letters, and that you've finished the tutorial. A new code sometimes won't work on a server still running the old version of the game: leave and rejoin. Codes generally work once per account. If it still fails, tap "didn't work" to let other players know.
Is there a code for free Robux or characters in Anime Dice?
No. Codes give Lucky Spins, Trait Rerolls, Gems, and Tickets. Anyone promising Robux, secret characters, or infinite luck in exchange for your login is running a scam.
