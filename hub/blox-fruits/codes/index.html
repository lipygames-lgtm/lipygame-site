How we check

Before a code goes on the list, it's checked against the official source (when the game publishes its codes) or against two independent sources. We show where each one comes from:

  • Official sourcepublished by the game itself or by its studio.
  • Confirmed by 2 sourceslisted as active by independent sources that don't copy each other.

A code with only one source, a conflicting status, or the look of a recycled list stays out. Players' "it worked" and "didn't work" votes help us quickly pull codes that have stopped working.

Official channels checked: Official Blox Fruits X account (@BloxFruits), Official Blox Fruits Discord, Official page on Roblox.

Frequently asked questions

Why didn't the code work?
Make sure you've already picked Pirates or Marines and that you copied the code exactly. If it still fails, it may have expired: tap "didn't work" to let other players know.
Is there a free fruit code?
No. Codes give double EXP, a Stat Reset, or Beli. Anyone promising free fruits, Robux, or an admin account is running a scam.
Why are some codes under "May have expired"?
Because the sources disagree on them (one says it works, another says it expired). They don't leave the page: they show up in that section, below the active ones, with what each source says. The active list only includes codes from an official source or confirmed by independent sources.
