引き換え方法

  1. RobloxでNosniy Gamesのグループに参加一部のコードは、スタジオのグループに参加している人しか使えません。
  2. RIVALSを開いてチュートリアルを終える引き換え画面は、射撃場で最初のタスクを終えると表示されます。
  3. 画面下のRewardsをタップ報酬メニューをいちばん下までスクロールしてください。コードのエリアはメニューの最後にあります。画面はアップデートで変わることがあるので、見つからないときはメニューで「Rewards」を探してください。
  4. ユーザー名を入力してVerifyをタップコードの入力欄を使えるようにするため、Robloxのユーザー名の入力を求められます。一部のサイトによると、この手順を進めるには、ゲームの開発者（SenseiとNosniy）をフォローする必要もあるそうです。
  5. コードを入力してRedeemをタップ入力欄には「Enter a special code here」と表示されています。報酬はそのままインベントリに届きます。

確認方法

リストに載せる前に、各コードをゲームの公式情報（ゲームがコードを公開している場合）か、2つの独立した情報源で確認しています。各コードには、出どころを次のように表示しています。

  • 公式発表ゲーム公式またはスタジオが発表したコード。
  • 2つの情報源で確認互いに転載し合っていない、独立した複数の情報源で有効と掲載されているコード。

情報源が1つしかないコード、状況が食い違っているコード、使い回しのリストに見えるコードは載せません。プレイヤーの「使えた」「使えなかった」の投票が、使えなくなったコードをすばやくリストから外す助けになっています。

確認した公式チャンネル： Nosniy Games公式X（@NosniyGames）, Nosniy Games公式Discord, Roblox上の公式ページ.

よくある質問

BACK2BACKとNOSNIYGAMESONTOPのコードは終了しますか？
はい。Nosniy Games自身が、ベストスタジオ賞とベストシューティングゲーム賞の受賞記念として、どちらも期間限定の報酬だと発表しています。早めに使いましょう。
Keysが無限にもらえるコードはありますか？
いいえ。コードでもらえるのは少量のKeys、チェスト、見た目アイテムです。KeysやRobuxを無限にくれると言ってくるのは詐欺です。
